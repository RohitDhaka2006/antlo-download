# Antlo download site

Static GitHub Pages site for the Android APK download page.

## Live URL

After Pages is enabled: `https://<github-username>.github.io/antlo-download/`

Also available at: `https://<github-username>.github.io/antlo-download/download.html`

## Update the APK link

Edit `download.html` and `index.html` — replace the `href` on `#android-download` with your EAS build artifact URL.
